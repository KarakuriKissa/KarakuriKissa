## TM Tools for Maya の更新

初回だけ `Update_TM_Tools.py` をダウンロードし、Mayaの3D画面へドラッグ＆ドロップします。完了後にMayaを再起動してください。

次回からはMayaの **TM Tools → TM Toolsを更新... → 今すぐ更新** だけで更新できます。
